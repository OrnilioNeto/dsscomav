# 🛡️ Admin Controllers - Gestão Administrativa

Esta subpasta contém controladores específicos para funções de alto privilégio e relatórios de auditoria.

### Estrutura:

- **CertificateManagementController.php**: Centraliza a lógica de auditoria. Permite filtrar certificados por validade, datas e exportar dados brutos para conformidade legal.
- **Relatórios Especializados**: Gerencia a lógica de agregação de dados para os PDFs de auditoria da diretoria.

### Funcionalidade:
Garante que a lógica de "Business Intelligence" do sistema (quem assistiu o quê e quando) esteja separada da lógica de entrega de vídeo.
